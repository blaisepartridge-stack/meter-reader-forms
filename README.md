# Meter Reader Forms

Web forms for Water Corporation Meter Reading Management candidates.

- Onboarding forms: https://blaisepartridge-stack.github.io/meter-reader-forms/onboarding.html

- Outlook helper (used by the Candidate Intake Tracker): https://blaisepartridge-stack.github.io/meter-reader-forms/compose.html opens a new, unsent Outlook email from details in the link after #. It stores nothing.
